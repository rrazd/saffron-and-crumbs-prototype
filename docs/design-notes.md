# Saffron & Crumbs

## Current storefront

- `/catalogue/` is a full-page 14-product grid with Cakes, Cake cups, and Gift boxes filters.
- `/cakes/<product-id>/` provides full product pages with Catalogue breadcrumbs, a large product photo, description, price, and Add to cart.
- The only purchase customization is an optional printed message or handwritten calligraphy note. Message text and style are stored on separate persistent cart lines.
- CAD and USD prices are illustrative placeholder amounts, not live exchange-rate conversions. Browser locale/time zone suggests a default; the visible currency selector overrides it and persists across pages.
- `data/products.json` holds catalogue names, images, descriptions, and prices. `npm run build` regenerates the catalogue and product pages.
- `npm test` checks storefront navigation, filters, currency, messages, cart migration, and real SVG ingredient visibility.
- Footer links align right. The logo monogram is the favicon.
- Hero ingredients are correctly isolated using the actual hidden attribute for SVGs, with an outward burst followed by gentle floating. Reduced-motion preferences disable animation.

Run `npm install`, then `npm run dev` for local preview. The site is static and checkout remains a preview.
